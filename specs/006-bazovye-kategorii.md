# Базовые и собственные категории

## Для кого и зачем
Для человека, который хочет сразу выбирать тему из выпадающего списка или создать свою, задать цель и видеть отдельный прогресс.

## Что должно быть
- Восемь базовых тем сразу доступны без подключения: «Повседневное общение», «Путешествия», «Работа», «Учёба», «Еда», «Дом», «Здоровье», «Хобби». Это названия без готовых слов.
- Базовые и собственные категории доступны в выпадающих списках добавления, изменения и смены категории активной карточки. По умолчанию — «Без категории». Кнопок подключения нет.
- При загрузке добавляются только отсутствующие темы. Существующая одноимённая категория используется без потери её цели, карточек и отметок; сравнение без крайних пробелов и регистра. Повторная загрузка не создаёт дублей.
- Во вкладке «Категории» есть «Своя категория» и «Мои категории» со всеми темами. Сначала «Без категории», затем старые категории в прежнем порядке и недостающие базовые в порядке набора.
- Создание своей категории: обязательное название и необязательная цель. Название обрезается по краям; пустое или повторное отклоняется с подсказкой. Своя тема доступна наряду с базовыми.
- Цель — безопасное целое положительное число. Пустое поле означает отсутствие цели. Ноль, отрицательные, дробные и нечисловые значения отклоняются; категория не создаётся, ввод остаётся для исправления. Успешное создание очищает форму и оставляет текущую вкладку.
- У каждой категории видны «Добавлено: N», «Знаю: K», цель T и «До цели: R», где R = max(T − K, 0). Без цели — «Цель не задана».
- При цели показаны процент и полоса «К цели»: округлённое K / T × 100 в пределах 0–100%. Пока K < T, максимум 99%; 100% и «Цель достигнута» только при K >= T. Без цели полоса и процент скрыты.
- Если N < T, видно «Добавьте ещё D», где D = T − N. Цель можно изменить или снять пустым полем.
- Действия с карточками сразу пересчитывают показатели. Общий прогресс сохраняет прежнюю формулу; пустые темы и цели на него не влияют.
- После изменений категории, цели и карточки сохраняются в localStorage. После F5 базовые темы доступны без дублей, старые данные сохранены. Ошибки сохранения видны независимо от вкладки.

## Примеры
- На чистой странице открыть добавление слова → в выпадающем списке уже есть «Путешествия» и остальные базовые темы, ничего подключать не нужно.
- Ранее есть « работа » с целью 10 и шестью карточками, четыре известны → одна категория, цель и карточки сохранены.
- Создать «  Кино  » с целью 10 → «Кино» доступна наряду с базовыми; добавлено 0, знаю 0, до цели 10, к цели 0%, «Добавьте ещё 10».
- Повторить «кино» или создать «Работа» при наличии базовой темы → подсказка, копия не добавляется. Цель 0 или 1,5 → категория не создаётся.
- Цель 10, добавлено 6, знаю 4 → остаток 6, 40%, «Добавьте ещё 4». Добавить четыре неизвестные → предупреждение исчезает, процент прежний.
- Цель 3, добавлено 4, знаю 4 → остаток 0, 100%, «Цель достигнута».
- Цель 1000, знаю 999 → 99%, остаток 1. Отметить последнюю → 100% и достижение цели.
- Из 8 карточек 3 известны → 38%. Пустые базовые темы и изменение целей не меняют общий процент.

## Ограничения
- Только локальные HTML, CSS и JavaScript без npm, библиотек, внешних ресурсов и отправки данных в интернет. Запуск двойным щелчком по index.html.
- Сохраняются вкладки и оформление. Русский интерфейс, кнопки и поля не меньше 44px, ширина 375px без горизонтальной прокрутки; длинные названия переносятся. Не показывать undefined или null.
- Готовые словари, фильтр обучения по категории, удаление и переименование категорий не входят в функцию.
- Возможности specs/001–005 и требования к целям сохраняются, кроме явно описанного появления базовых тем.
- README.md обновляется после последнего шага. Новые файлы тестов не создаются.
