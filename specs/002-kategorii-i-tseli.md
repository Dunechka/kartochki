# Категории слов и цели

## Для кого и зачем
Для одного человека, который собирает слова по темам и хочет видеть, сколько слов уже знает, сколько осталось до цели и достаточно ли карточек для её достижения.

## Что должно быть
- Можно создать категорию с названием. Пробелы по краям удаляются; пустое название и повтор названия без учёта регистра отклоняются с подсказкой.
- Каждая карточка относится к одной категории. При добавлении можно выбрать категорию; без выбора используется «Без категории».
- Уже сохранённые карточки попадают в «Без категории» без потери текста, порядка и отметок. Эту категорию не нужно создавать вручную.
- У активной карточки видна категория; её можно сменить, сохранив слово, перевод и отметку знания.
- Для каждой категории, включая «Без категории», можно задать и изменить цель: целое положительное число слов, которые нужно отметить «Знаю». Изначально цель не задана. Пустое поле снимает цель; ноль, отрицательные, дробные и нечисловые значения не сохраняются, показывается подсказка.
- У каждой категории видны «Добавлено: N», «Знаю: K», «Цель: T» и «До цели: R», где R = max(T − K, 0). При отсутствии цели показывается «Цель не задана», остаток и предупреждение не показываются.
- Если добавлено меньше цели, показывается «Добавьте ещё D», где D = T − N. Предупреждение исчезает, когда карточек достаточно; наличие карточек само по себе не означает достижения цели.
- При достижении цели показывается «Цель достигнута». Число известных карточек может превышать цель, остаток не бывает отрицательным.
- Общий прогресс по всем карточкам: «Знаю K из N» и процент K / N × 100 с округлением до целого. При отсутствии карточек — «Знаю 0 из 0» и 0%. Каждая карточка учитывается один раз, включая «Без категории»; цели на общий процент не влияют.
- Добавление, смена категории и отметки «Знаю» / «Не знаю» сразу обновляют все связанные показатели. Повторное нажатие не меняет числа повторно.
- Категории, цели и принадлежность карточек сохраняются в localStorage и восстанавливаются после F5 вместе с существующими данными. Ошибка сохранения показывается пользователю.

## Примеры
- «Работа»: цель 10, добавлено 6, знаю 4 → до цели 6, предупреждение «Добавьте ещё 4».
- «Работа»: цель 10, добавлено 12, знаю 4 → до цели 6, предупреждения о нехватке нет.
- Цель 2, добавлено 3, знаю 3 → до цели 0, «Цель достигнута».
- Всего 8 карточек, из них 3 отмечены «Знаю» → «Знаю 3 из 8», 38%.
- Перенос известной карточки из «Без категории» в «Работа» меняет показатели обеих категорий, общий прогресс остаётся прежним.

## Ограничения
- Только HTML, CSS и JavaScript без библиотек, npm и внешних ресурсов. Данные не отправляются в интернет; запуск двойным щелчком по index.html.
- Русский интерфейс, кнопки и поля не меньше 44px, ширина 375px без горизонтальной прокрутки. Не показывать undefined или null.
- Существующие добавление, переворот, выбор карточки и отметки продолжают работать. Слово и перевод обязательны, пробелы по краям обрезаются.
- Цель не привязана к дню или сроку; расписание повторений, фильтрация по теме, удаление и переименование категорий в эту функцию не входят.
- README.md обновляется после последнего шага. Новые файлы тестов не создаются.

- [ ] Пройден сценарий leverage → рычаг влияния → переворот → «Знаю» → F5.
