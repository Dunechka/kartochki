# Удобная структура приложения

## Для кого и зачем
Для человека, который открывает страницу прежде всего для повторения слов. Карточка должна быть доступна сразу, без прокрутки через категории и формы.

## Что должно быть
- Вместо длинной страницы — три переключаемых раздела: «Учить», «Слова», «Категории». Одновременно виден один раздел. Навигация доступна в начале каждого раздела, активный пункт заметен, переключение работает с клавиатуры.
- При открытии и после F5 выбран раздел «Учить», режим «Все слова». Большой вступительный блок заменён коротким заголовком. Общий прогресс показан компактно в разделе «Учить» перед тренировкой.
- В разделе «Учить»: общий прогресс, режим повторения, активная карточка, «Знаю» / «Не знаю», подсказка и смена категории карточки. Кнопки отметок расположены сразу под карточкой; дополнительные действия — ниже.
- На экране 375×667px при обычной короткой карточке, закрытой подсказке и масштабе 100% видны английское слово и обе кнопки отметок без прокрутки. Длинный текст может увеличить высоту; содержимое не обрезается.
- В разделе «Слова»: кнопка «Добавить слово», раскрывающая форму добавления, и существующий список с выбором, изменением и удалением. По умолчанию форма добавления закрыта. Форма изменения находится в этом же разделе; при открытии фокус переходит в неё и форма становится видна.
- Успешное добавление открывает «Учить» с новой карточкой английской стороной. Ошибки ввода оставляют форму открытой с подсказками. Выбор слова из списка открывает «Учить» с выбранной карточкой. Существующий фильтр повторения продолжает действовать и для списка.
- В пустом состоянии «Учить» есть кнопка «Добавить слово»: она открывает раздел «Слова» и форму с фокусом на поле слова. Такая же кнопка доступна при завершённом повторении.
- В разделе «Категории»: создание категорий, их показатели и цели. Количество категорий не увеличивает высоту раздела «Учить».
- Переключение разделов само по себе не меняет активную карточку, её сторону, режим повторения, отметки или введённые в формы данные. Закрытие формы добавления скрывает её без очистки ввода. После F5 несохранённый ввод не восстанавливается.
- Предупреждение об ошибке сохранения видно независимо от открытого раздела.
- На компьютере используется более широкая область: в «Словах» открытая форма и список могут стоять рядом; на телефоне — друг под другом. Навигация не перекрывает содержимое.

## Примеры
- Открыть страницу с сохранённым leverage → сразу видна тренировка. Перевернуть → «рычаг влияния», нажать «Знаю» → счётчик увеличился на 1. Формы и категории не нужно прокручивать.
- Открыть «Слова» → «Добавить слово», ввести `  leverage  ` → `  рычаг влияния  ` и сохранить → открыт раздел «Учить», новая карточка активна, крайние пробелы удалены.
- Попробовать добавить слово с пустым переводом → остаётся открытая форма с подсказкой, новая карточка не появляется.
- Начать ввод слова, перейти в «Категории» и обратно → ввод сохранён. Перевернуть активную карточку, перейти в «Слова» и обратно без выбора другой → перевод остаётся виден.
- В «Словах» нажать на другое слово → открыт раздел «Учить» с выбранной карточкой. Нажать «Изменить» → форма доступна в «Словах», данные карточки не изменены до сохранения.
- Нажать F5 из «Категорий» → открыт раздел «Учить» в режиме «Все слова»; слова, отметки, категории и цели сохранены.

## Ограничения
- Только локальные HTML, CSS и JavaScript, без библиотек, npm и внешних ресурсов. Запуск двойным щелчком по index.html, данные только в localStorage.
- Существующие возможности из specs/001–004 сохраняются, кроме явно описанного расположения блоков и переходов между разделами.
- Интерфейс на русском, кнопки и поля не меньше 44px. На ширине 375px нет горизонтальной прокрутки; длинные слова и названия переносятся.
- Слово и перевод обязательны, крайние пробелы обрезаются. Не показывать undefined или null.
- Новые способы тренировки, поиск, сортировка, фильтр по категориям и изменение оформления всей страницы в эту работу не входят. Сохраняется текущая цветовая гамма.
- README.md обновить после реализации: описать разделы и ручную проверку. Новые файлы тестов не создавать.
